ملاحظتك في محلها تماماً؛ النموذج التجريبي السابق اختصر التقييم في 6 مدخلات فقط، بينما الأوراق المرفقة تحتوي فعلياً على **70 حقلاً تشخيصياً وسريرياً** موزعة على 3 صفحات للاستمارة التشخيصية، بالإضافة إلى **22 بنداً إرشادياً** للتعامل مع أطفال طيف التوحد.

فيما يلي الدراسة التحليلية الشاملة وجرد كامل لجميع الأسئلة والحقول مع الدليل المعماري ومنطق احتساب النقاط (Scoring Logic) لتبني الكود عليه بشكل كامل:

## أولاً: الجرد الشامل لحقول الاستمارة التشخيصية (المدخلات)

تتكون المنظومة التشخيصية في الأوراق من 8 أقسام فرعية يجب تمثيلها بالكامل في الواجهة البرمجية:

### 1. استمارة البيانات الأساسية وعوامل الخطورة (19 حقلاً)

تنقسم برمجياً إلى بيانات إدارية، وأسئلة طبية تُستخدم لحساب **"مؤشر الخطورة الحيوية والوراثية"**:

* **البيانات الإدارية والديموغرافية:** التاريخ، الاسم، تاريخ الميلاد (والعمر بالسنوات)، الجنس (ذكر/أنثى)، العنوان، التليفون، عمل الأب، عمل الأم، عدد الأخوة، وترتيب الطفل بين إخوته.


* **أسئلة عوامل الخطورة (تُبرمج كخيارات نعم/لا مع حقل تفاصيل):**
1. هل توجد إعاقة في العائلة أو حالة مشابهة؟


2. هل تعرض الطفل لنقص أكسجين بعد الولادة؟


3. هل تعرضت الأم لحادث أو مرض في فترة الحمل؟


4. ما هي صلة القرابة بين الوالدين؟


5. ما هو نوع الولادة (طبيعية / قيصرية / متعسرة)؟


6. ما هي مدة الحمل (كامل / خديج)؟


7. كم كان سن الأم وقت الولادة؟


8. هل تعرضت الأم للأشعة في أثناء الحمل؟ وفي أي شهر إن وجد؟


9. هل تناولت الأم فترة الحمل أي أدوية؟ وفي أي شهر؟





### 2. تاريخ نمو الطفل والفحوصات الطبية (6 حقول)

تُستخدم هذه الأسئلة لكشف **"التأخر النمائي الشامل"** أو **"الإعاقة السمعية/العصبية"**:

1. متى ظهرت الأسنان؟


2. متى بدأ الحبو؟


3. متى بدأ المشي؟


4. هل حدثت مشكلات سمعية؟ وما هي؟


5. هل تم استشارة طبيب الأنف والأذن والحنجرة؟


6. هل تم استشارة طبيب المخ والأعصاب؟



### 3. الفحص العضوي لأعضاء النطق (12 حقلاً)

أساسية جداً لتشخيص اضطرابات النطق العضوية وعسر الكلام (Dysarthria)، وتُبرمج كحقول تقييم (سليم / يوجد مشكلة):

* **فحص التشوهات والإصابات:**
1. هل توجد تشوهات في الفك وسقف الحنك؟


2. هل يوجد رابط لسان (اللسان المربوط)؟


3. هل توجد إصابات في الحنجرة؟




* **فحص الوظائف الحركية الفموية (Oral-Motor):**
4. كفاءة الشفط.
5. كفاءة المضغ.
6. كفاءة النفخ.


* **فحص سلامة الأعضاء:**
7. الفك.
8. اللسان.
9. الشفاه.
10. عضلات الوجه.
11. البلعوم.
12. الأسنان.



### 4. الأعراض المصاحبة والسلوكيات المرضية (9 حقول)

تُبرمج كمقياس متدرج (Scale من 0 إلى 3: لا يوجد، بسيط، متوسط، شديد) وتضم:

1. الانتباه والتركيز (يُقاس مستوى التشتت أو الضعف).


2. مدة التواصل البصري (يُقاس مستوى القصور في التواصل).


3. نشاط زائد (فرط الحركة).


4. توتر وقلق.


5. خجل.


6. عنف.


7. خوف.


8. عناد.


9. التحكم في عملية البول (نعم يتحكم / لا يتحكم - تبول لا إرادي).



### 5. التاريخ اللغوي (4 حقول)

تُقارن بعمر الطفل لتحديد حجم الفجوة اللغوية:

1. متى بدأت المناغاة؟


2. متى كانت أول كلمة؟


3. متى كانت بداية الجمل؟


4. كم كلمة ينطقها الطفل حالياً؟



### 6. اللغة الداخلية - الإدراك المعرفي ما قبل اللغوي (4 حقول)

تقيس المهارات الإدراكية الأساسية التي تسبق الكلام، وتُبرمج كخيارات (مكتسب = 0، ضعيف = 1، غير مكتسب = 2):

1. استخدام ودوام الشيء (إدراك وظيفة الأدوات واستمرار وجودها عند إخفائها).


2. العلاقة السببية (ربط السبب بالنتيجة).


3. الانعكاسية (التقليد والمحاكاة).


4. ثبات الشيء.



### 7. اللغة الاستقبالية - المجموعات الضمنية (14 حقلاً)

تقيس ما يفهمه الطفل ويميزه عند الإشارة إليه، وتُبرمج كقائمة اختيار (Checkboxes) أو تقييم لكل مجموعة:

1. أجزاء الجسم.


2. الأهل.


3. الفاكهة.


4. الخضروات.


5. أدوات المائدة.


6. الأجهزة المنزلية.


7. أثاث المنزل.


8. حيوانات المزرعة.


9. حيوانات الغابة.


10. الأعداد / الأشكال الهندسية.


11. الألوان.


12. المواصلات.


13. الحروف الهجائية.


14. مجموعات أخرى.



### 8. اللغة التعبيرية (5 حقول)

تقيس قدرة الطفل على إنتاج اللغة وتوظيفها، وتُقيّم من 0 (سليم) إلى 2 (قصور شديد):

1. التركيب الصوتي (مخارج الحروف وتكوين الكلمات صوتياً).


2. حجم المفردات (الحصيلة اللغوية المنطوقة).


3. السرد والحكاية (القدرة على رواية حدث متسلسل).


4. المضمون (معنى الكلام وترابطه).


5. السياق (توظيف الكلام في الموقف الاجتماعي المناسب).

## ثانياً: منطق التشخيص وتوزيع العلامات (Scoring & Rules Engine)

الصفحة الأخيرة من الاستمارة تحدد **8 اختبارات مقننة** و**4 محاور علاجية** كمخرجات نهائية. لبرمجة محرك ذكي يقترح هذه الاختبارات بدقة، نربط المدخلات بالمخرجات وفق المعادلات السريرية التالية:

| الاختبار المقترح في الورقة

 | الشروط البرمجية لتفعيله (Triggers) بناءً على حقول الاستمارة |
| --- | --- |
| **1. اختبار الذكاء (IQ)**

 | • تأخر في تاريخ النمو الحركي (الأسنان، الحبو، المشي).

<br>

<br>• قصور في "اللغة الداخلية" (مجموع نقاطها $\ge 4$ من 8).

<br>

<br>• وجود عوامل خطورة حيوية (نقص أكسجين بعد الولادة، قرابة الوالدين، إعاقة بالعائلة).

 |
| **2. اختبار الفايلاند / الصورة الجانبية**

 | • عدم التحكم في عملية البول (تأخر مهارات الاعتماد على النفس).

<br>

<br>• تأخر شامل في تاريخ النمو مع ضعف في اللغة الاستقبالية والتعبيرية معاً.

 |
| **3. اختبار اللغة**

 | • معرفة أقل من 50% من المجموعات المتوقعة لعمره في "اللغة الاستقبالية" (من أصل 14 مجموعة).

<br>

<br>• تأخر في "التاريخ اللغوي" (تأخر الكلمة الأولى أو الجمل).

<br>

<br>• ضعف في "حجم المفردات" أو "المضمون" في اللغة التعبيرية.

 |
| **4. اختبار كارز / جليام (للتوحد)**

 | • ضعف شديد في "مدة التواصل البصري" (الدرجة $\ge 2$).

<br>

<br>• ضعف في "الانعكاسية" (التقليد) ضمن اللغة الداخلية.

<br>

<br>• خلل واضح في "السياق" (اللغة التعبيرية) مع وجود أعراض مصاحبة مثل العناد أو الخوف أو التوتر.

 |
| **5. اختبار كونرز (لفرط الحركة وتشتت الانتباه)**

 | • درجة مرتفعة في "نشاط زائد" (الدرجة $\ge 2$).

<br>

<br>• ضعف واضح في "الانتباه والتركيز" (الدرجة $\ge 2$).

<br>

<br>• وجود سلوكيات اندفاعية مثل "عنف" أو "عناد".

 |
| **6. اختبار النطق**

 | • وجود أي مشكلة في قسم "الفحص العضوي للطفل" (تشوهات الفك/الحنك، رابط لسان، ضعف النفخ/الشفط/المضغ، اللسان، الشفاه).

<br>

<br>• وجود خلل في بند "التركيب الصوتي" في اللغة التعبيرية.

 |
| **7. اختبار التلعثم**

 | • الطفل ينطق جملاً (في حقل بداية الجمل)، لكنه يسجل درجات مرتفعة في الأعراض النفسية المصاحبة: "خجل" + "خوف" + "توتر وقلق" مع تعثر في "السرد والحكاية".

 |
| **8. اختبار تدافع الكلام (دالي)**

 | • الطفل يمتلك حصيلة مفردات وجمل، لكن لديه مشكلة في "التركيب الصوتي" و"السرد والحكاية" مترافقة مع "نشاط زائد" (سرعة واندفاع في الكلام).

 |

## ثالثاً: خوارزمية توليد "البرنامج العلاجي المقترح"

في الجزء السفلي من ورقة النتائج، يوجد 4 بنود للبرنامج العلاجي، ويمكن للكود توليد محتواها تلقائياً كالتالي:

1. التركيز والانتباه:


* إذا كان هناك ضعف في الانتباه أو التواصل البصري أو نشاط زائد، يكتب النظام: *"تدريبات زيادة مدة الانتباه السمعي والبصري وتقليل المشتتات"*.




2. اللغة السلبية (الاستقبالية):


* يقرأ الكود المجموعات التي لم يتم تحديدها في قسم "اللغة الاستقبالية" ويطبعها تلقائياً: *"التدريب على تمييز وإدراك المجموعات الضمنية التالية: (يذكر المجموعات الناقصة من الـ 14 مجموعة)"*، بالإضافة لأي مهارة ناقصة في "اللغة الداخلية" (مثل العلاقة السببية أو دوام الشيء).




3. اللغة الإيجابية (التعبيرية):


* يولّد التوصية بناءً على النقص في قسم "التاريخ اللغوي" و"اللغة التعبيرية": إما *"تحفيز المناغاة وإنتاج الكلمة الأولى"*، أو *"زيادة حجم المفردات وتكوين جمل قصيرة"*، أو *"تنمية مهارات السرد والحكاية وتوظيف السياق اللغوي"*.




4. الأصوات:


* إذا وُجدت مشاكل في "الفحص العضوي" أو "التركيب الصوتي"، يطبع النظام: *"تدريبات أعضاء النطق الحركية (النفخ، الشفط، المضغ، وتقوية عضلات اللسان والشفاه) وتصحيح مخارج الأصوات"*.

## رابعاً: توظيف الورقات الثلاث الأولى (الـ 22 بنداً للتوحد)

الورقات الثلاث الأولى (ومن ضمنها الورقة المقلوبة) تحتوي على **22 بنداً** تحت عنوان **"اعتبارات التعامل مع الأطفال ذوي اضطراب طيف التوحد"**. يمكنك توظيفها برمجياً بطريقتين:

* **الطريقة الأولى (كتقرير إرشادي تلقائي):** إذا أوصى المحرك بتطبيق **"اختبار كارز / جليام"**، يقوم النظام بإظهار هذه البنود الـ 22 كـ "دليل إرشادي للأخصائي والأهل" مقسمة حسب الفئات التالية:


* **إرشادات التواصل اللفظي (البنود 1 إلى 6):** التكلم بهدوء، إعطاء تعليمات قصيرة ومحددة، التكلم ببطء والانتظار بين الجمل لترجمة المعلومات، ثبات الكلمات المستخدمة (أشر إلى، وين، أعطيني)، إقران الكلمات بالصور، واستخدام عبارات إيجابية ("ستحصل على الشيبس بعد الانتهاء" بدلاً من صيغة النفي).


* **إرشادات التدريب وتنفيذ المهام (البنود 7 إلى 13، و18، و22):** التدرج من الأسهل للأصعب، تقديم المساعدة اللفظية أو الجسدية (كمسك يد الطفل) وتخفيفها تدريجياً، التكرار للتغلب على بطء التعلم، تقليل المشتتات وجعل فترة التدريب من 15 إلى 20 دقيقة، التنويع في التعزيز (مادي كالطعام، معنوي كالابتسامة، أو بالنشاط)، تعميم الخبرة في مستويات مختلفة من التجريد، التأني وعدم استعجال الاستجابة، تنويع الأنشطة اليومية لمنع الملل (بند 18)، ونمذجة النشاط أمام الطفل قبل التنفيذ (بند 22).


* **إرشادات الضبط السلوكي والحسي (البنود 14 إلى 17، و19 إلى 21):** الحزم دون صراخ أو ضرب وإلزام الطفل بإعادة أدوات اللعب لمكانها، بناء حلقة تواصل كفريق عمل واحد مع الأهل، البحث عن سبب السلوك غير المرغوب وتدريبه على سلوك بديل، عدم إظهار الغضب أمام الطفل، مراعاة عدم الملامسة المباشرة بسبب الحساسية اللمسية (بند 19)، الابتعاد عن الأصوات المرتفعة (بند 20)، والمحافظة على التواصل البصري المناسب (بند 21).

## خامساً: هيكل البيانات البرمجي الجاهز (JSON Schema)

لتوفير وقتك في كتابة الحقول يدوياً، هذا الكائن البرمجي (JavaScript Object) يحتوي على هيكلة جميع الحقول المقروءة من الصور؛ يمكنك نسخه مباشرة إلى مشروعك وبناء الواجهة (Form) وحلقة الفحص (Loop) عليه:

```javascript
const diagnosticSchema = {
  // 1. استمارة البيانات الأساسية وعوامل الخطورة
  basicInfo: {
    name: "",
    birthDate: "",
    age: 0,
    gender: "male", // male | female
    phone: "",
    address: "",
    fatherJob: "",
    motherJob: "",
    siblingsCount: 0,
    childOrder: 1,
    riskFactors: {
      familyDisability: false,       // هل توجد إعاقة في العائلة؟
      oxygenLackAfterBirth: false,   // نقص أكسجين بعد الولادة؟
      motherIllnessInPregnancy: false, // حادث أو مرض للأم بالحمل؟
      parentsConsanguinity: false,   // صلة قرابة بين الوالدين؟
      difficultBirthType: false,     // نوع ولادة متعسرة؟
      prematurePregnancy: false,     // مدة حمل غير مكتملة؟
      motherAgeAtBirthRisk: false,   // سن الأم وقت الولادة (خطر)؟
      xrayExposure: { exposed: false, month: "" }, // تعرض للأشعة؟
      medicationsInPregnancy: { taken: false, month: "" } // أدوية بالحمل؟
    }
  },

  // 2. تاريخ نمو الطفل
  developmentalHistory: {
    teethingDelayed: false,          // تأخر الأسنان
    crawlingDelayed: false,          // تأخر الحبو
    walkingDelayed: false,           // تأخر المشي
    hearingProblems: { exists: false, details: "" }, // مشكلات سمعية
    entConsulted: false,             // استشارة أنف وأذن وحنجرة
    neuroConsulted: false            // استشارة مخ وأعصاب
  },

  // 3. الفحص العضوي للطفل (true = يوجد مشكلة / غير سليم)
  organicExam: {
    jawPalateDeformity: false,       // تشوهات الفك وسقف الحنك
    tongueTie: false,                // رابط لسان
    larynxInjuries: false,           // إصابات في الحنجرة
    suckingWeakness: false,          // ضعف الشفط
    chewingWeakness: false,          // ضعف المضغ
    blowingWeakness: false,          // ضعف النفخ
    jawIssue: false,                 // مشكلة في الفك
    tongueIssue: false,              // مشكلة في اللسان
    lipsIssue: false,                // مشكلة في الشفاه
    facialMusclesIssue: false,       // مشكلة في عضلات الوجه
    pharynxIssue: false,             // مشكلة في البلعوم
    teethIssue: false                // مشكلة في الأسنان
  },

  // 4. الأعراض المصاحبة وسلوكيات مرضية (0: طبيعي/لا يوجد، 1: بسيط، 2: متوسط، 3: شديد)
  behavioralSymptoms: {
    poorAttention: 0,                // ضعف الانتباه والتركيز
    poorEyeContact: 0,               // ضعف مدة التواصل البصري
    hyperactivity: 0,                // نشاط زائد
    anxiety: 0,                      // توتر وقلق
    shyness: 0,                      // خجل
    violence: 0,                     // عنف
    fear: 0,                         // خوف
    stubbornness: 0,                 // عناد
    bedwetting: false                // عدم التحكم في عملية البول
  },

  // 5. التاريخ اللغوي
  languageHistory: {
    babblingDelayed: false,          // تأخر المناغاة
    firstWordDelayed: false,         // تأخر أول كلمة
    sentencesDelayed: false,         // تأخر بداية الجمل
    wordsCount: 0                    // كم كلمة ينطقها
  },

  // 6. اللغة الداخلية (0: مكتسب، 1: ضعيف، 2: غير مكتسب)
  innerLanguage: {
    objectUseAndPermanence: 0,       // استخدام ودوام الشيء
    causality: 0,                    // العلاقة السببية
    reflexivityImitation: 0,         // الانعكاسية
    objectConstancy: 0               // ثبات الشيء
  },

  // 7. اللغة الاستقبالية (true = يعرف المجموعة، false = لا يعرفها)
  receptiveLanguage: {
    bodyParts: false,                // أجزاء الجسم
    family: false,                   // الأهل
    fruits: false,                   // الفاكهة
    vegetables: false,               // الخضروات
    tableware: false,                // أدوات المائدة

    furniture: false,                // أثاث المنزل
    farmAnimals: false,              // حيوانات المزرعة

    colors: false,                   // الألوان
    transportation: false,           // المواصلات
    alphabet: false,                 // الحروف الهجائية
    otherGroups: false               // مجموعات أخرى

  expressiveLanguage: {
    phoneticStructure: 0,            // التركيب الصوتي
    vocabularySize: 0,               // حجم المفردات
    narration: 0,                    // السرد والحكاية
    content: 0,                      // المضمون
    context: 0                       // السياق
  }
};

```

هل ترغب في أن أكتب لك دالة التحليل الكاملة (JavaScript Function) التي تطبق شروط الجدول أعلاه على هذا الـ `JSON` وتخرج لك التقرير النهائي، أم تفضل كتابتها بنفسك؟
